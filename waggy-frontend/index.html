    CANONICAL API
    
        
    POST /api/v1/presentation/workbench
    
        
    Role-aware application contract. Fail-closed input. One engine call, four projections.
    
        
    PREFERENCE RECOMPUTE
    
        
    POST /api/v1/dogs/{dog_id}/recompute
    
        
    Validates excluded ingredients / monthly budget, stores them as preferences, then runs the same Waggy engine. Returns a system-owned explanation of why packages changed. Does not overwrite prior analyses. Chat cannot choose packages.
    
        
    GET /api/v1/dogs/{dog_id}/analyses/compare
    
        
    Diffs two stored analysis digests. Does not run the engine or an LLM.
    
        
    RAW ENGINE API
    
        
    POST /api/v1/analyze
    
        
    Raw analyze JSON. Legacy silent defaults. Not the workbench response. Protected by API_KEYS when configured.
